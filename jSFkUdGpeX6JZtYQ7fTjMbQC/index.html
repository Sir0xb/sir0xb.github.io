解决 Github 邮件中提示的问题

独立域名指向 Github 服务器 IP ，并在站点增加 CNAME 文件之后，收到了无数个 GitHub 提示邮件。

只要通过 GitHub 帮助中的内容，做一下 IP 调整，邮件就不会再来了。

打开控制台输入以下命令(pages 地址自行修改)

dig sir0xb.github.io +nostats +nocomments +nocmd

得到如下结果：
