WinXP 无线提示“区域中找不到无线网络”

确定不是病毒或网卡驱动等问题的前提下，用如下方法： 原因是 WinXP 的 Wireless Zero Configuration 服务依赖于 Eventlog 服务。

打开 服务，找到 Eventlog 服务启用。 如果你发现 Wireless Zero Configuration 的依存关系有 Event Log 这项，重新启动 Wireless Zero Configuration 服务。 如果没有 Eventlog 依赖项，运行 regedit 进入注册表，依次进入下面项：

[HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services]

找到 WZCSVC 项目, 双击它的值项 DependOnService，在值设置窗口输入一行：Eventlog （不含引号），点击确定后保存。 正常值有下面三项：

RpcSs
Ndisuio
Eventlog

加入 Eventlog 依存关系。 重新启动 Wireless Zero Configuration 服务。 又可以看到可爱的无线列表了。
