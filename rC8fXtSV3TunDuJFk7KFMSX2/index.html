XML生成Java类

前提条件：

JDK1.6 环境变量设置妥当

工具JAR包：trang.jar 下载地址：http://www.163disk.com/fileview_269095.html

步骤：

cmd进入xml所在目录，输入

java -jar trang.jar xxx.xml xxx.xsd

完成之后目录应该多出一个XSD文件。

再输入

xjc -extension xxx.xsd

完成之后，会在所在目录的generated目录下生成一大堆java文件。 其中ObjectFactory.java是工厂类。
