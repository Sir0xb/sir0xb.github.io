Oracle数据库被锁解决方法

查找被锁用户：

select t2.username,t2.sid,t2.serial#,t2.logon_time
from v$locked_object t1,v$session t2
where t1.session_id=t2.sid order by t2.logon_time;

在杀掉被锁的session

alter system kill session '776,17529';
